# 定调修订：「人情味打法」从产品真理（总开关）退为红线；产品真理改为「管理决策层」；展示面数字政策放宽

> 修订 [ADR-0015](0015-product-tone-human-advisor-debrand-saas-naming.md)（定调与品牌声音）。不动 ADR-0015 已落地的具体 surface 决策（Playbooks / "Worth a closer look" / 人卡去血条等——它们多数本来就是红线的实现，继续有效）。不动 ADR-0016（两个方向都敢下判断）。

## 背景

2026-07-03 创始人裁决（当晚面向证券金融公司投资人路演，landing 转投资叙事时暴露的结构性问题）：

1. ADR-0015 把「人情味 / 资深前辈在你耳边」定为**总开关**——"一切命名、文案、取景"以它为准，且红线测试②（"像 AI 工具在自夸效率吗？→ 砍"）事实上否决了一切 dashboard / 效率 / 商业语言。这在面向投资人讲市场空白、盈利模式、降本增效、ROI 时**说不出话**：合伙人的盈利模式材料里已经自然出现 "Growth Command Center" / dashboard 等词，与总开关直接冲突。
2. 旧数字红线（"没跑出真测量结果之前，页面上不出现任何数字"）把商业设计数字（定价、收入结构、TAM 测算、ROI 假设）也一并禁了——而金融听众恰恰靠数字理解生意。

## 决策

### 1. 产品真理改为「管理决策层」

> **产品真理 = 管理决策层：帮 manager 做出更稳妥、可追溯、算得清账的人事与项目决策。**

命名、文案、取景的总开关从"人 + 人情味"换成这句。人情味 / 前辈人设**退为红线 + 风格资产**：在面向使用者的产品表面它仍是默认声音（ADR-0015 的具体决策继续有效），但它不再是产品的自我定义，也不再否决其他表达。

### 2. 人情味退为红线（永远有效，任何表面）

- **永不量化 / 评判 / 标签化任何一个人**（无分数、无等级、无血条、无人格断言）。
- **文案不得让被讨论的那个人觉得"被处理"**（旧红线测试①原样保留）。

旧红线测试②（自夸 agent/自动化/效率 → 砍）与③（温暖前辈会这样说吗 → 重写）**降级为产品表面的风格建议**，不再是任何表面的否决项：dashboard / 效率 / 降本增效 / 商业语言在营销、路演、投资人材料中放开使用。

### 3. 展示面数字政策（取代旧"零数字"规矩）

- **允许 mock / 预估数字上展示面**，条件：代码注释中标注其性质（mock / illustrative / 假设）。
- **结果形态的数字**（读起来像实测结果的，如 "94% risks caught"）另加**页面可见微标注**（zh "设计目标值，上线前测算" / en "illustrative target, pre-launch"）——主动交底，防金融听众追分母时连带真数字失信（phil 2026-07-03 审）。
- **模型形态的数字**（定价、收入结构、bottom-up TAM/SOM 公式、ROI 假设账）可直接上页，公式/假设可见即为标注。
- **不变**：eval 分数 / 用户数据等**实测口径**的数字仍禁——没跑出真人评分之前不上 scorecard（诚实声明条保留）。

### 4. 角色职责随动

Dana 从"人情味 vs 工具感总把关"收窄为**红线门神**（只对决策 2 的两条有否决权）；tone 观感降级为建议。Phil / Will 在商业叙事表面上不再受总开关约束。

## 被否的替代

- **维持总开关、只给路演开一次性豁免**：豁免会无限增生（每次商业场合都要豁免），且掩盖真实转向——策略已经变了，文档应如实记录。否。
- **人情味彻底删除（连产品表面也转商业腔）**：产品对使用者（manager/HR）的温度是留存资产，且红线本身就来自它。否——降级不是删除。
- **数字全面放开（含伪造实测）**：一个被识破的假实测会传染到真定价。否——mock 只放开到"模型/目标值"口径。
