## 功能规格

### F2 晨间分诊区（ADR-0017 原判的真正执行）
「你的团队」顶部一个"今天需要你"队列区：卡片化、颜色分层（沿用 sage/honey/terracotta 左边条语法）、可勾选。条目从真数据派生（handoffs/blockers），零捏造。三动作（ADR-0017 决策 5）：done → 对勾、收进"Taken care of today / 今天已照料"堆、计数安静更新；discard → 淡出；重条目 → 一键带上下文飞进议事室。**语言红线**：人的读数一律定性人话；项目状态可以硬（due/blocked/进度）。无 P0 徽章、无统计数字 chips、无 capacity 读数。

### F3 Follow-ups 跟进区
待办列表：今天 / 本周 / 之后 分组；每条带来源标签（来自分诊 / 来自议事室 / 来自快问 / 来自多看一眼 / 手动添加）；完成、编辑、删除、历史（可恢复）。**接线必须是真的**：advice 卡建议动作、分诊卡、矛盾卡的"加入跟进"都真写 store（合伙人版此处全是假按钮，是本功能最大的教训）。一期本地态（内存 + localStorage），二期照 saveAsk/fetchAsk 模式接后端（阶段 D）。附动作深链：message 类动作提供"起草邮件"mailto 深链——Avery 起草、你来发（ADR-0015 authorship 原则）。

### F4 A closer look 矛盾点独立页
照合伙人形态：对照卡（左"文件里的说法"/ 右"实际信号"）+ 解决 / 忽略 + 历史折叠。**派生必须诚实**：只从真 live 语料派生（如项目状态读稳但 blockers 非空 → 一张矛盾卡，claim 引项目自述、evidence 引 blocker 行），不捏造；点名类矛盾（沉默成员等）本期不做（走 07-13 评分开关，roadmap）。每卡带"直接问问本人"→ 跳议事室并预填快问语境。命名用锁定词族，页面不出现"现实差距/差距/gap"。

### F5 提示面
- 议事室空态 4 个建议问题 chips（点击即发问；措辞泛化、不预设语料内容）。
- 通知铃铛：只由真实事件驱动（ingest 完成 / run 完成 / 快问回执收齐 / 新矛盾卡），零手写假通知（合伙人版的 5 条硬编码通知是反例）。

### F6 合规免责页脚
改写合伙人版"AI 管理辅助约束"段：Avery 只辅助判断、不替代负责人决策；产出需复核；不得作为重大人事决策唯一依据。口吻走我们的（备忘录腔，非监管腔）。EN 定稿 + ZH M3。

### F7 Onboarding 向导
首次进入 v02 时的可跳过向导（覆盖层，非路由）：① 上传资料（**真接 ingest**，非假拖放）→ ② 团队信息 → ③ 选 playbooks（8 项可勾选；**勾选结果持久化**进本地配置，Playbooks tab 槽位按所选呈现）→ ④ 完成。合伙人版的"连接工具"假开关步**不做**（假 OAuth 不诚实）；"创建账号"步不做（无账号体系）。
