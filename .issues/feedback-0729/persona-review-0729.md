# 酒店经理视角 · 首轮 persona check（2026-07-29）

**姿势**：本地 build+preview(5173) + mock 后端(8137)，三亚 demo 满态（16 人/6 项目/9 文件），
Playwright 逐屏截图 + innerText + 一次真实提问；0 console error。截图在 session scratchpad
`persona-capture/`（单机产物不入库，关键数字已录入本文）。
**人设**：三亚度假酒店总经理/业主。日常 AI 用法零散：微信群催人、Excel 台账、偶尔问豆包写通知。
**评审问题**（Danny 07-29 出题）：Avery 的输出要长什么样，他才能无痛无感地把这些零散工具换掉。

## 一、这次实测里已经做对的（别在后面的改造里弄丢）

1. **首页就是老板的桌面**：「今天有几件事等你定」+ 6 张决策卡 + 每张带「凭什么这么判」
   展开归因——这是他真需要的形态，语言已经相当白。
2. **「多看一眼」屏的并排对照**（文件说法 vs 实际信号）在酒店语料上一眼有用：
   婚宴尾款条款没过法务、儿童乐园缺看护、房态回写延迟——全是他会拍桌子的事。
3. **信任锚点密度足**：「来自你上传的文件」「没有一处是编的」「文档未提及≠0」贯穿全站。
4. **语料说行话**：BEO、房态回写、现炒/预制口径、进场时点——不是互联网黑话。

## 二、让他出戏的地方（按严重度）

### 🔴 P1 问答链路三重劝退——这是他唯一会拿来跟豆包对比的入口
- 问「明天中层例会是几点？」→ 一张 **2145 字符** 9 节报告卡（判读/事实/推断/依据/
  置信度/下一步/1:1 开场白/何时拉 HR/谁把关）。
- 回答卡装在**要拖拽缩放的画板**里：截图实证默认视口只露出卡的前几行，其余在折叠线下，
  读答案要先看懂「拖动平移 · 滚动缩放 / 重置视图」。
- mock 罐头是英文 1:1 谈话建议，与问题无关（mock 口径，长度/结构是真行为、语义不是）；
  且生产 LLM 链路从未走通过一次（07-28 handoff agent 线 #4）——**核心问答实际从未被
  真实用户完整体验过**。
- ✅ 对策已拍板（07-29）：分流+砍样板+淘汰画板；本文是它的用户侧证据。

### 🔴 P2 「起草消息 / 直接问本人」是替代零散工具的钩子，但本轮没验发送后闭环
老板的日常单位是发通知、催人、要回话。团队屏每张卡都露这两个按钮（对的），但快问发出后的
收集/回执动线本轮未实测。**下一轮 persona check 专测这条链**：从「起草消息」到对方回复
回流进系统，顺不顺直接决定粘性。

### 🟡 P3 决策卡理由机械重复
6 张卡里 4 张理由一字不差（「挂着 1 条未解阻塞；自报『正常』但挂着未解阻塞」）。
老板第二天就学会无视。判定理由应带具体内容（哪条阻塞、阻塞的是什么），别只贴规则名。

### 🟡 P4 议事室空态的建议问题是「管理咨询腔」，不是他的问题
四个开场（谁需要我搭把手/哪个交接等着谁…）没有一个像酒店老板会问的
（明天入住率多少？婚宴排期跟工程施工冲突吗？）。建议问题应从他的数据里长出来
（有婚宴 BEO → 「今天婚宴还有什么没确认？」）。

### 🟡 P5 同一个动作三个名字（「词 token」问题）
实测动线里：tab 叫「待办清单·跟进」、首页按钮「加到待办」、团队屏按钮「加到跟进」、
板块「今日待办」、跟进屏自称「跟进」。全词表改名时把**动作词**一起统一，不只改屏名。

### 🟡 P6 「会议室」误译出现在正文
操作手册屏副标题「会议室早已在跑的那些打法」= 已知 3 处翻译漂移之一，随改名统一修。

### ⚪ P7 跟进/笔记两屏在 demo 动线里是空屋子
0 条跟进、1 条系统自动笔记。demo seed 该预铸几条，或首访引导点一次「加到跟进」，
否则老板看不到这两屏活起来的样子。

### ⚪ P8 移动端顶栏 tab 溢出截断
390×844 下「议事室」切半、后 5 tab 不可见——与 uiux-narrow-0728 在修问题互证。

### ⚪ P9 免责声明每屏整句重复
9 屏页脚同一段人事决策免责长文。法务必要，但老板视角=「每页都在强调它不可靠」。
可收敛为首次提示 + 设置页常驻。

## 三、正面回答 Danny 的问题：输出应该长什么样

1. **问答默认形态 = 一段话直答 + 出处**（哪份文件哪行），像微信里靠谱下属的回复；
   完整报告卡改为「展开完整分析」或复杂问题才出。
2. **产出物直接落进对应容器**：通知草稿→草稿箱、待办→跟进清单、方法→操作手册，
   不再都挤在议事室一张画板上——即「artifacts 分配到容器」的具体解法。
3. **入口贴着他的数据**：建议问题、快捷动作从当日数据生成，让他第一周每天都有
   「点一下就有用」的理由；这是「无痛无感」的实际含义——不是学新系统，是旧习惯换了个更懂
   他公司的对话框。
